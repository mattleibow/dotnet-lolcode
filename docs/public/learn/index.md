# Learn LOLCODE

Programming is giving a computer a sequence of precise instructions. LOLCODE
makes that sequence deliberately playful without changing the underlying ideas:
data, decisions, repetition, decomposition, and tests. Follow these lessons in
order; every code block is compatible with the repository's 1.2 profile.

1. [Foundations](foundations.md): program structure, output, values, and names.
2. [Values and decisions](values-and-decisions.md): input, casting, math,
   comparisons, boolean logic, and branching.
3. [Repetition and text](repetition-and-text.md): loops, strings, and switches.
4. [Functions and an application](functions-and-app.md): reuse, recursion, and
   a complete guessing game.

The [FizzBuzz walkthrough](../tutorials/fizzbuzz.md) is a short checkpoint.
After the path, build the [calculator](../tutorials/calculator.md) or
[adventure game](../tutorials/adventure.md). Keep the
[language reference](../language/reference.md) nearby; it is a shelf, not a
substitute for practicing.
