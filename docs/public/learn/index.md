# Learn LOLCODE

Programming is writing precise instructions that transform input into useful
output. LOLCODE gives those instructions playful words, but the skills are the
same ones used in every language: values, decisions, repetition, decomposition,
testing, and planning.

## Pick a route

- **Never programmed before?** Follow the twelve-part
  [beginner course](course.md). It starts with files, editors, terminals, and
  output, then finishes with a complete stable-1.2 application.
- **Already use .NET?** Take the shorter
  [C#, Visual Basic, and F# route](dotnet/index.md). It concentrates on semantic
  differences and interoperability instead of reteaching programming.
- **Want a guided build?** Use the [tutorials](../tutorials/index.md) to
  construct FizzBuzz, a calculator, or an adventure game in stages.
- **Want working source to explore?** Browse the canonical
  [sample gallery](../language/samples.md).

Keep the [language reference](../language/reference.md) nearby. It is a shelf
for exact rules; the course is where you practice using them.
