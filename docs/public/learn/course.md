# Beginner course

This course assumes you have never programmed. You only need curiosity and,
for local work, a text editor plus the .NET 10 SDK. The
[browser playground](../getting-started/playground.md) works without an
installation.

Each lesson follows the same learning loop:

1. **Predict** what a short program will do.
2. **Run** it and compare the result with your prediction.
3. **Explain** each instruction in your own words.
4. **Modify** one part and observe the change.
5. **Create** a small program without copying the example.

Solutions are explained, not merely shown. Type examples yourself when you can:
the small mistakes you make and repair are part of learning.

| Lesson | You will be able to... |
| --- | --- |
| [01 Your first program](first-program.md) | Create a source file, run it, and connect source code to terminal output. |
| [02 Values, output, variables](foundations.md) | Store and change text, numbers, truth values, and NOOB. |
| [03 Input and calculations](values-and-decisions.md) | Read text, convert it deliberately, and calculate results. |
| [04 Decisions and program flow](decisions.md) | Choose instructions with comparisons, TROOF values, `O RLY?`, and `WTF?`. |
| [05 Repetition and text](repetition-and-text.md) | Build safe loops and work with text, escapes, and interpolation. |
| [06 Functions and a guessing game](functions-and-app.md) | Split work into functions and assemble an interactive program. |
| [07 Finding errors and testing](debugging-and-tests.md) | Distinguish syntax, logic, and runtime failures and use test tables. |
| [08 Planning a complete program](planning-programs.md) | Model state and decompose a program before coding it. |
| [09 Objects and program state](objects-and-state.md) | Understand the 1.3-draft object progression without confusing it with stable 1.2. |
| [10 Growing into a .NET project](project-workflow.md) | Move from one file to a repeatable multi-file build. |
| [11 Libraries, files, and resources](files-and-libraries.md) | Use development libraries while respecting files, handles, and host capabilities. |
| [12 Build and share an application](capstone.md) | Plan, test, package, and explain a complete application. |

> [!TIP]
> Work in order through lesson 8. Lessons 9–11 deliberately introduce
> development features and project tooling. Lesson 12 offers both a stable
> 1.2 core capstone and an optional development project capstone.
