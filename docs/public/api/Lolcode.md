# Lolcode namespace

The public compiler APIs live beneath the
<xref:Lolcode.CodeAnalysis> namespace. Start with
<xref:Lolcode.CodeAnalysis.Syntax.SyntaxTree> to parse source,
<xref:Lolcode.CodeAnalysis.LolcodeCompilation> to inspect and emit a program,
or <xref:Lolcode.CodeAnalysis.Scripting.LolcodeScript> for in-memory execution.

The [compiler course](../compiler-course/index.md) explains how these public
entry points connect to the internal compiler pipeline.
