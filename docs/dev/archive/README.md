# Documentation archive

This directory separates historical source material from current guidance.

- `pdb-implementation-notes/` preserves a planning and review packet created
  before Portable PDB support was completed. Its status statements and
  checklists are superseded by the current implementation and tests, so the
  folder is intentionally excluded from the public DocFX build.

Historical language specifications live in
`docs/public/reference/archive/` because they are part of the published
language history.

Current compiler architecture belongs in `docs/dev/compiler-architecture.md`,
current language behavior in `docs/public/reference/language-spec.md` and
`docs/public/reference/implementation-profile.md`, and current documentation
authoring guidance in `docs/README.md`.
