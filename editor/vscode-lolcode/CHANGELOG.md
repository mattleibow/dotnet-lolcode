# Changelog

All notable changes to the LOLCODE extension are documented in this file.

## 0.1.0

- Initial Marketplace release with LOLCODE syntax highlighting and editing rules.
- Add snippets for programs, variables, output, input, conditionals, loops,
  functions, calls, and switches.
- Add **LOLCODE: Install .NET Templates** to install the project, source-file,
  and file-based-app templates.
